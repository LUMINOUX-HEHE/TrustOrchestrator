# 11 — How to demo this project to a teacher (20 minutes)

Everything below is executable locally in one command. The demo is
live: real processes, real mTLS, real crypto — nothing simulated in the
trust path.

## The one command

```sh
bash deploy/live-demo.sh
```

It does, in order (the full ~2–3 min script):

1. rebuilds every binary from source (`go build`)
2. runs the **council ceremony**: 5 members, threshold 3, one FROST
   share file per member, prints the group key — "the root key never
   exists"
3. materializes CA + leaf certs (`to-identity`) and boots a live fleet:
   orchestrator (`to-orchestrator serve`) + 3 watchdogs on real mTLS
   sockets, replaying the benchmark evidence
4. boots the **gateway** on `127.0.0.1:8090` with `-council-pub <group
   key>`, creates tenant "acme", fires honest traffic + an attack, and
   shows `DETECTED` land on the signed chain timeline
5. prints the admin token and the dashboard URL — the last act is you
   clicking "recover" on the dashboard (or via curl)

Requirements: Go 1.22+, bash (Git Bash / WSL on Windows). Ports: 8333
(fleet), 8090 (gateway); port 8080 is in Windows' excluded range and
bind fails silently — the script avoids it.

## The 10-minute script for the teacher

| moment | show | say |
|---|---|---|
| 0:00 | `bash deploy/live-demo.sh` | "Every binary you see is a real process on this machine; in production they'd be five hosts, and the mTLS here is real sockets." |
| 0:30 | council ceremony output | "Three of five members can sign this chain's rollback. The root key never exists in memory, in files, anywhere. That's the point." |
| 1:00 | fleet verdicts: HEALTHY then DETECTED | "3 of 5 watchdogs screaming → the fleet declares the evidence untrusted." |
| 1:30 | `curl localhost:8090/v1/orgs/acme/timeline` | "An append-only signed chain per org. The file on disk is AES-GCM sealed — at rest there is no recoverable key." |
| 2:00 | `to-council recover` | "three share files threshold-sign the rollback fork — offline, no network, no root key material." |
| 2:30 | paste fork+commit to `/v1/orgs/acme/recover` | "The gateway verified the FROST signature against the group key before adopting the fork. No shard ever crosses this API." |
| 2:45 | open the dashboard, click through | "Users, RBAC, webhooks, audit search, backup — one static HTML file." |
| 3:00 | `go test ./...` tail | "Everything in the README is a passing test: kill-tests, fuzz, TLA+ model checks." |

## What to skip on live demo

`make benchmark`, TLA model checks, terraform/helm — mention they exist
and point to `specs/`, `deploy/`, `reports/` as artifacts. Keep the live
demo to the script.

## The "is anything faked?" question

Answer from `docs/09-limitations.md`, honestly and confidently:

* transport/network is loopback-sockets, not 5 VMs
* no hardware enclave (SGX/TPM)
* everything cryptographic is real and tested: Ed25519, SHA-256, FROST
  3-of-5, TLS 1.3 mTLS

## Files to have open during the demo

- `deploy/live-demo.sh` — the story
- `docs/10-gateway.md` — API/RTM reference
- `trust-orchestrator-final-report.md` — the report
- `reports/evidence.json` — generated by `make benchmark`, used by fleet

## Reset between demos

```sh
rm -rf bin .demo && make build
```
